###### 动作脚本是什么 ######
动作脚本（.mt）是机器人的最小动作单元：一次 run_action_script 调用播放一份脚本，机器人做出一个完整动作（如向前走一段、转向、停止）。脚本都放在动作脚本目录（缺省 scripts/）下，硬件加载后常驻上电，可以在一次任务里连续执行多个脚本。

###### 仿真环境的动作脚本 ######
在仿真环境里，你使用以下动作脚本：

```plain
sim_forward.mt  =>  向前前进一段距离
sim_backward.mt =>  向后退一段距离
sim_left.mt     =>  向左转
sim_right.mt    =>  向右转
sim_stop.mt     =>  停止
```

> 完整清单用 list_action_scripts 查询，以返回结果为准；上面没有列到的脚本，先看它的首行注释或试跑一次观察效果，再决定是否用于任务。
