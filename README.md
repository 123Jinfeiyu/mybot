# bot4cj

基于仓颉和 Linux I2C 接口的硬件机器人库

## 项目介绍

`bot4cj` 是一个专为硬件机器人设计的库，基于仓颉编程语言和 Linux I2C 接口，提供了便捷的硬件控制能力，支持多种传感器和执行器。

编译方法：
```bash
make
cjpm build
```

## 解析器

程序内置了动作脚本解析器，连接pca9685后使用如下方法使用：

```bash
# 蜘蛛机器人脚本
cat ss/step.bot | cjpm run
```

## 动作脚本

项目中包含的动作脚本在ss文件夹下面，这些动作脚本的定义如下

```textplain
1号舵机    =>    左下水平关节
2号舵机    =>    左下垂直关节
3号舵机    =>    右下水平关节
4号舵机    =>    右下垂直关节
5号舵机    =>    右上水平关节
6号舵机    =>    右上垂直关节
7号舵机    =>    左上水平关节
8号舵机    =>    左上垂直关节
9号舵机    =>    云台1
19号舵机 =>    云台2
```
