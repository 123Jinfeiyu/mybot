🤖 bot4cj 项目深度分析文档

本文档对 bot4cj 项目进行全面、详细的分析，涵盖项目架构、每个模块的实现细节、算法原理、数据流、缺陷与改进建议。目标读者为零基础学习者。

1. 项目总览

1.1 项目是什么

bot4cj 是一个机器人硬件脚本解析器，基于仓颉（Cangjie）编程语言和 Linux I2C 接口。它的核心思想是：

用一种自定义的"矩阵式脚本语言"来描述机器人的硬件构成和动作序列，然后解析并驱动真实硬件执行这些动作。

简单类比：如果把机器人比作一个演员，那么 .mt 脚本就是剧本，bot4cj 就是导演——它读剧本、安排演员（硬件）、指挥表演（执行动作）。

1.2 项目能做什么

🔌 驱动 PCA9685

📐 读取 MPU6050
实时获取姿态数据，带卡尔曼滤波
🔊 控制扬声器
以声音频率替代延时

通过网络接口远程提交脚本并执行

关键概念：MatrixVars_Hardware（硬件变量）

这是整个项目的核心抽象。每种硬件（I2C、PCA9685、Servo、Speaker...）都被封装为一个硬件变量，它们：

  1. 通过闭包持有真实的硬件对象（如 I2C_Orig、PCA9685、Servo）
  2. 通过 JsonValue 进行统一接口通信（输入 JsonValue，输出 JsonValue）
  3. 有生命周期：build() 初始化，play() 执行，destroy() 释放

4. 矩阵式脚本语言（.mt）详解

4.1 语法规则

矩阵式脚本是一种声明式、表格型的领域特定语言（DSL），用于描述机器人的硬件构成和动作序列。

基本结构：

@MatrixName          ← 矩阵开始，@ 后跟名称
 col1  col2  col3;   ← 第 0 行：列名声明
 val1  val2  val3;   ← 第 1 行起：数据行
 val4  -    val6;    ← "-" 表示沿用上一行同列的值
@
  • 注释：以 # 开头到行末
  • 占位符 -：在数据行中，- 表示"与上一行同一列的值相同"，减少重复书写。

4.2 各矩阵对象的含义

矩阵名用途关键列
@Alias定义参数别名name, alias
@I2C定义 I2C 总线设备name, path
@PCA9685定义舵机控制板name, I2C, addr
@MPU6050_BIND定义陀螺仪name, I2C, addr
@Speaker定义扬声器name, channels, sample_rate, volumn, max_f, min_f
@Servo定义舵机name, max, min, offset, controller, channel
@Action定义动作序列格式为 硬件名.参数名

4.3 @Action 矩阵详解

@Action 是最核心的矩阵，它定义了机器人的动作序列：

@Action
s1.A  s2.A  s3.A  ...  spk.F  spk.delay;   ← 列名：硬件变量.参数名
  45     -    45  ...     10        200;     ← 第1行：站立姿态
  90     -     -  ...      -         20;     ← 第2行：左后方抬起
  ...
@

4.4 蜘蛛机器人动作示例解读

以 scripts/test.mt 为例，这是一个 8 足蜘蛛机器人的行走步态：

@Action
s1.A  s2.A  s3.A  s4.A  s5.A  s6.A  s7.A  s8.A  s9.A  s10.A  spk.F  spk.delay;
  45     -    45     -    45     -    45     -    90     90     10        200;  # 站立
  90     -     -     -     -     -     -     -     -      -      -         20;  # 左后方抬起
  45     -     -     -     -     -     -     -     -      -      0        500;  # 恢复站立
   -     -    90     -     -     -    45     -     -      -      -         20;  # 右后方抬起
  ...
@
  • s1-s8 是 8 个舵机（4 条腿，每腿 2 个关节）
  • s9-s10 是云台舵机
  • spk.F 是扬声器频率，spk.delay 是延时

5.1 MatrixObject 类

用途：表示解析后的一个矩阵对象，对应脚本中 @name ... @ 之间的内容。

MatrixObject {
    name: String                         ← 矩阵名称

}
方法功能

5.2 MatrixParser 类

用途：将输入流逐字符解析为 MatrixObject 对象。

算法：有限状态机（FSM）

标志含义
flag是否遇到结束的 @
nl是否处于新行起始位置
cm是否处于注释中
nm是否正在解析名称行（@ 后的第一行）
输入字符 c
├── 如果在注释中 (cm=true)
│   ├── c == '\n' → 注释结束，nl=true, cm=false
│   └── 其他 → 忽略
├── 如果在新行起始 (nl=true)
│   ├── c 是空白 → 维持现状
│   ├── c == '\n' → 空行，行号+1
│   ├── c == '@' 且未命名 → 开始名称行，nm=true
│   ├── c == '@' 且已命名 → 结束标志，flag=true
│   └── 其他 → 内容字符，加入缓冲区
├── 如果不在新行 (nl=false)
│   ├── 在名称行且遇空白 → 提交名字
│   ├── 遇空白/制表符 → 提交当前元素
│   ├── c == ';' → 提交元素并提交行
│   └── 其他 → 加入缓冲区

6. 机器人结构模块详解

6.1 MatrixVars_Hardware 基类

这是整个硬件抽象的核心。

MatrixVars_Hardware（基类）
├── things: (JsonValue) → JsonValue    ← 事件回调（核心！）
├── rise: Option<() → Unit>           ← 初始化回调
├── free: Option<() → Unit>           ← 释放回调
├── play(input) → things(input)        ← 执行动作
├── build() → rise()                   ← 初始化硬件
└── destroy() → free()                 ← 释放硬件

为什么用 JsonValue 通信？不同硬件需要不同参数：

  • PCA9685 需要 {"channel": 0, "angle": 90.0}
  • I2C 需要 {"mode": "set_addr", "addr": 0x40}
  • Servo 需要 {"angle": 180.0}
  • Speaker 需要 {"frequency": 1000.0, "delay": 400}

6.2 各硬件变量类

MtVars_I2C（I2C 变量）

things 支持 4 种模式：

  • get_fd：获取文件描述符
  • set_addr：设置从机地址
  • set_val：写寄存器
  • get_val：读寄存器

MtVars_Servo（舵机变量）

Servo.setAngle() 逻辑：

角度 = 输入角度 + 偏移值(offset)
如果 角度 > 最大值(max) → 角度 = max
如果 角度 < 最小值(min) → 角度 = min
调用回调函数设置角度

8. 数学库详解

8.2 Matrix1 矩阵类

数据布局：一维数组 Array<FP32>，行优先存储。

arr[row * col + col]  ← 元素访问公式
运算符号含义形状要求
矩阵加法A + B逐元素相加同形状
广播加法A + s每个元素加标量-
矩阵减法A - B逐元素相减同形状
逐元素乘A * B逐元素相乘（Hadamard积）同形状
矩阵乘法A.dot(B)矩阵点积（MatMul）A.col == B.row
转置A.T()行列互换-

矩阵乘法算法（dot）：

对于结果矩阵的每个元素 (i, j):
    sum = 0
    对于 k in 0..A.col:
        sum += A[i, k] * B[k, j]
    结果[i, j] = sum

时间复杂度：O(m × n × k)

9. 神经网络模块详解

9.1 Nn1 全连接层

class Nn1 {
    inputno: Int64          ← 输入维度
    outputno: Int64         ← 输出维度
    weights: Matrix1        ← 权重矩阵 (inputno, outputno)
    bias: Matrix1           ← 偏置向量 (1, outputno)
    learning_rate: FP32     ← 学习率
    f: Af                   ← 激活函数
}

forward() 前向传播： a = f(Wx + b)

backward() 反向传播：

δ = errs * f'(z)             ← 误差 × 激活函数导数
weights_grad = x^T · δ       ← 权重梯度
bias_grad = δ                ← 偏置梯度
errs_up = δ · W^T            ← 传给上一层的误差

9.2 激活函数

函数公式导数用途
Sigmoidf(x) = 1/(1+e^(-x))f'(x) = f(x)(1-f(x))二分类输出层
ReLUf(x) = max(0, x)f'(x) = 1 if x>0, else 0隐藏层
Leaky_ReLUf(x) = x if x>0, else αxf'(x) = 1 if x>0, else α隐藏层
Tanhf(x) = tanh(x)f'(x) = 1 - tanh²(x)隐藏层
Softmaxf(x_i) = e^(x_i) / Σe^(x_j)雅可比矩阵多分类输出层

9.3 Xavier 权重初始化

σ = sqrt(2 / (fan_in + fan_out))      ← Xavier 正态
limit = sqrt(6 / (fan_in + fan_out))    ← Xavier 均匀（Glorot）

10. 卡尔曼滤波详解

卡尔曼滤波是一种最优估计算法，用于从含有噪声的测量数据中估计系统的真实状态。

一维卡尔曼滤波器 5 个核心公式

步骤公式含义
预测状态X_mid = A · X_last根据上一次最优估计预测当前状态
预测协方差P_mid = A · P_last + Q预测的不确定性增大（+系统噪声Q）
计算卡尔曼增益kg = P_mid / (P_mid + R)测量越可靠(R小)，增益越大
更新状态X_now = X_mid + kg · (dat - X_mid)用测量值修正预测值
更新协方差P_now = (1 - kg) · P_mid估计的不确定性减小

11. FFT 快速傅里叶变换详解

快速傅里叶变换（FFT）是一种高效计算离散傅里叶变换（DFT）的算法。将时域信号转换为频域表示。

DFT 公式： X[k] = Σ x[n] · e^(-j·2π·k·n/N)

算法：Cooley-Tukey 基-2 FFT —— 将 N 点 DFT 分解为两个 N/2 点 DFT，递归分解，时间复杂度从 O(N²) 降低到 O(N·log N)。

蝶形运算

对于每一级 l:
    对于每一组 j:
        对于每个蝶形 k:
            t = A[jl1k] · W[ij]           ← 旋转因子乘法
            A[jl1k] = A[jl0k] - t         ← 蝶形运算上支
            A[jl0k] = A[jl0k] + t         ← 蝶形运算下支

12.1 CNN 架构

卷积层前向传播

对于每个输出通道 oc:
    对于每个空间位置 (oh, ow):
        sum = bias[oc]
        对于每个输入通道 ic:
            对于每个核位置 (kh, kw):
                sum += weight[oc,ic,kh,kw] * input[ic,oh*stride+kh,ow*stride+kw]
        output[oc,oh,ow] = sum

__global__ void _devAdd(float* d1, float* d2, float* r, int64_t n) {
    int i = blockIdx.x * blockDim.x + threadIdx.x;  ← 计算全局线程ID
    if (i < n) {

18. 全局缺陷与改进建议

18.1 严重缺陷

编号缺陷位置详细说明严重程度
D1析构器调用时间不确定r.cj:28 仓颉的 GC 不保证析构器调用时间，I2C 文件描述符可能泄漏 高
D2扬声器仅延时未发声hd/snd.cj:17 play() 只 sleep，C++ 实现的 play_frequency() 未被调用 高
D3MPU6050 线程无法安全退出hd/MPU6050.cj:115 mpu6050_main() 是无限循环，pthread_cancel 可能在不安全点中断 高
D4I2C 锁系统线性扫描hd/I2C.cj:129 每次加锁/解锁都遍历 20 个元素的数组，O(n) 复杂度 中
D5xavierUniformInit 每个元素新建 Randommath/Ini.cj:30 循环内每次 DateTime.now().nanosecond + Random()，种子可能重复 中
D6Softmax 雅可比矩阵反向传播未正确使用math/Af.cj:246 softmax_jacobian 返回 n×n 矩阵，但 backward 调用者期望与输入同形状 高
D8tanh 导数输入错误math/Af.cj:194-206 计算 1 - x*x 用的是原始输入 x，应改为 1 - y*y 高
D9I2C 读寄存器返回 Int8 而非 UInt8hd/I2C.cj:81 负值寄存器数据会出错 中
D10MPU6050 ADDR_0 和 ADDR_1 相同hd/MPU6050.cj:14-15 两个地址常量都是 0x68，ADDR_1 应为 0x69 中
